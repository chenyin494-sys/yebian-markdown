# 网页在左，文档在手边

欢迎使用 **页边**。把它放在网页旁边，就可以随时翻阅自己的笔记。

## 从这里开始

1. 打开你自己的 Markdown 文件夹。
2. 在文件列表里选择一篇文档。
3. 在导航面板中选择「文章大纲」，快速跳到想读的段落。

直接点击这段正文即可修改内容，停笔后自动保存。顶部「☰」可以展开文件夹树。

> 浏览资料、查看项目说明、翻阅小说草稿，都可以从这块小小的侧边栏开始。

## 支持的排版

| 内容 | 效果 |
| --- | --- |
| **重点文字** | 加粗 |
| *随手标注* | 斜体 |
| `inline code` | 行内代码 |

```javascript
const notes = '把文档放在手边';
console.log(notes);
```
