# 页边 · 本地 Markdown 阅读器

在 ChatGPT 网页的 Chrome 侧边栏直接编辑排版后的 Markdown，把文档放在手边。当前版本：1.3.0。

## 这次更新

- **每个 ChatGPT 对话独立绑定**：按对话地址记住文件夹、当前文档、阅读位置和目录状态。重新打开同一对话可恢复自己的工作区；ChatGPT 项目内的同一对话也对应相同工作区。
- **阅读排版内直接编辑**：点击正文就能修改，标题、粗体、列表、引用、表格和代码块保留对应样式。停笔约 0.6 秒后将 Markdown 写回原文件，支持「保存」按钮和 Ctrl+S。
- **文件夹树**：按文件夹层级展示文档，点击箭头展开或收起，记住各层的展开状态；搜索时展开匹配文件所在的路径。
- **简洁入口**：顶部「☰」打开目录，文件目录和文章大纲在导航面板内切换，正文横向空间随之增加。
- **外部修改实时同步**：侧栏可见时约每 0.8 秒检查当前文件内容，切回页面时立即检查。外部编辑器保存后，阅读区与编辑区随之更新。
- **版本选择与草稿恢复**：本地编辑稿和磁盘内容同时变化时，保留编辑稿并展示外部版本，可选采用磁盘版本、保存自己的编辑稿或另存为副本。页面意外关闭或切换时，保留的草稿会在重新打开原对话时恢复。
- **中文输入与格式保留**：中文输入法完成组词后再保存，写回时保留 UTF-8 BOM 和 CRLF/LF 换行方式。
- 顶部工具栏压缩为 42 px，正文占据主要阅读区域。
- 文件目录、搜索、打开文件夹和文章大纲移到左侧可收起的导航栏。
- 窄窗口采用抽屉目录，选择文章或标题后自动收起；宽窗口支持目录与正文并排。
- 记住目录的展开状态；点击顶部「☰」、收起箭头、遮罩或按 Escape 操作目录。
- 仅在 `https://chatgpt.com/` 及其站内页面启用。切到其他网站时侧栏隐藏，扩展按钮变为灰色。

已从此文件夹加载扩展的用户：在 `chrome://extensions` 找到「页边 · 本地 Markdown」，点击卡片上的刷新按钮，然后回到 ChatGPT 页面重新打开扩展。如从另外的文件夹安装，将新版文件覆盖到对应目录后刷新扩展。

从 1.2.0 升级时，原有对话绑定继续使用。较早版本可在每个对话中选择对应文件夹，建立独立绑定。ChatGPT 首页与各个已创建的对话分别保存工作区；建立对话后，可在该对话中选择要长期绑定的文件夹。

## 安装（Chrome 116 及以上桌面版）

1. 解压 `页边-Markdown侧边栏.zip`，保留解压后的 `md-sidebar` 文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `md-sidebar` 文件夹。
4. 打开 `https://chatgpt.com/`，从 Chrome 工具栏的扩展菜单中固定「页边 · 本地 Markdown」，点击图标打开侧边栏。
5. 点击顶部「☰」展开目录，再点「打开文件夹」，选择存放 Markdown 的本地目录，按 Chrome 提示授予读取和写入权限。

如果侧边栏出现在左侧，进入 Chrome 设置 → 外观，搜索「侧边栏」，将位置设为右侧。位置由 Chrome 的全局设置控制。

本扩展的文件已打包完整，加载文件夹即可使用。

## 使用

- **打开文件夹**：扫描 `.md`、`.markdown`、`.mdown`、`.mkd`，包含子目录；按路径排序。`.git`、`.svn`、`node_modules` 目录自动跳过。
- **文件 / 拖入文件**：选择单篇或多篇 Markdown。获得文件句柄后支持持续编辑与同步；兼容导入方式产生的文件快照可通过「另存为」连接到可写入的本地文件。
- **搜索**：按文件名或相对路径筛选。
- **文件夹树**：点击文件夹箭头查看内部文件和下级目录；点击文档开始阅读与编辑。顶部「☰」展开或收起导航面板。
- **直接编辑**：点击段落、标题、列表项或表格单元格修改内容，Enter 新增段落，Ctrl+B 加粗，Ctrl+I 斜体，Ctrl+Z 撤销，Ctrl+Y 重做。首次编辑时可按 Chrome 提示授予写入权限。
- **保存 / Ctrl+S**：立即保存；底部显示待保存、正在保存、已保存或需处理的情况。
- **另存为**：在左侧文件目录里选择，将当前稿件保存为另一份本地 Markdown。
- **大纲**：在导航面板中选择「文章大纲」，根据文档标题生成跳转导航。
- **A− / A+**：调整正文字号，支持 12–24 px。
- **明暗主题**：点击右上角按钮切换；首次使用跟随系统。
- **实时同步**：约每 0.8 秒检查当前文件实际内容；外部修改同步到阅读和编辑区。实际延迟受浏览器调度和磁盘速度影响。此开关控制外部内容同步，编辑自动保存持续启用。
- **刷新**：重新扫描目录；新增、删除或重命名文档后点击刷新。
- **恢复工作区**：按对话地址保存文件夹、文件、阅读位置和编辑状态；Chrome 要求再次授权时，点击「继续读取」恢复。恢复的待保存草稿可通过「保存」确认写回。

支持标题、粗体、斜体、列表、任务清单、引用、表格和代码块的排版编辑。代码块以等宽字体显示。保存时保留未修改块的原始 Markdown 写法；修改过的块按对应结构生成 Markdown。内嵌 HTML 等特殊片段作为保留块展示，原始源码随文档保存。

## 图片和链接

文件夹模式支持所选目录内的相对图片路径，例如 `![插图](images/example.png)`。`../` 可访问所选目录内的上级文件夹。`/images/example.png` 从所选目录根部查找。

按住 Ctrl 点击链接即可打开：指向已扫描 Markdown 的相对链接在侧边栏内跳转，支持标题锚点，例如 `[第二章](chapters/02.md#开始)`；网络链接在新标签页打开。普通点击可编辑链接文字。网络图片显示文字占位，阅读时文档资源保留在本地。

## 本地数据

扩展按用户授权读取和写入所选目录或文件。Markdown 在扩展内解析，DOMPurify 清理渲染内容；扩展使用本地打包脚本。各对话的文件句柄、工作区、编辑草稿和最近一次写入前的备份保存在扩展 IndexedDB，阅读偏好、位置缓存及待保存草稿的快速副本保存在扩展本地存储。

写入前核对磁盘内容；来自本扩展的并发写入按文件名排队。发现外部版本变化时进入版本选择。与外部程序之间的检查和写入属于两个文件操作，遇到高频同时写入时，可通过版本选择、另存为和本地备份保留工作成果。

支持 UTF-8 文档，单篇文档大小上限为 10 MB；其他编码的文档可先在编辑器中转换为 UTF-8。每次扫描会枚举所选目录，选择具体的笔记或项目文件夹可以加快加载。

## 文件结构

- `manifest.json`：Manifest V3 配置，请求 `sidePanel` 及 `https://chatgpt.com/*` 网站权限，用于识别该站点标签页。
- `background.js`：根据网址启用侧边栏及工具栏按钮。
- `sidepanel.html`、`style.css`、`panel.js`：侧边栏界面、文件读取和渲染。
- `paths.js`：本地路径解析和标题锚点。
- `storage.js`：按对话保存工作区、文件快照与编码格式。
- `document-session.js`：编辑草稿、自动保存、外部同步和版本冲突处理。
- `editor-source.js`：排版编辑器源码，基于 Tiptap / ProseMirror，将改动序列化为 Markdown，并保留未修改的原始块。
- `vendor/rich-editor.js`：已打包的编辑器，可离线使用。
- `vendor/licenses/`：编辑器所用依赖的版本清单与许可证。
- `示例文档/`：可用于首次体验的示例。
